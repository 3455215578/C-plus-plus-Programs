#                       	                                                                                                                                                     字符串是如何工作的?

#### 一.定义

​	C++的字符是用单引号。

​	双引号默认是char指针(字符串)，字符串就是字符组成的数组（指针)。



​	char str[] = "content";（用数组定义，**可以修改字符串**）

​	char* str = "content"; （用指针定义，实际上是**用一个指针指向字符串字面量的内存位置**，而字符串字面量是存储在内存的只读位	置，因此该字符串被定义之后是不可被修改的。如果想要一个更长的字符串，需要去分配一个全新的内存并删除旧的字符串。）



#### 二.终止符

​	在字符串地址后的 00 被称为空终止符(**'\0'**)，用于告知字符串在哪里结束。对于单个字符组成的字符数组，如果最后没有终止符，字	符后面会有许多"内存护卫"cc，告知我们这些内存不属于数组。



#### 三.std::string是如何工作的?

​	std::string本质上就是一个char数组和一些内置函数，它有一个接受参数为char指针或者const char指针的构造函数。



​	若要将字符串作为参数传入函数，一定要**避免在函数内被拷贝(按值操作)**， 因为复制字符串意味着我们必须在堆上动态创建一个全新	的char数组来存储我们以前已经得到的完全相同的文本。可以选择指针或引用来解决。



#### 四.字符串字面量

​	在C++中，R"( ... )" 是一种特殊的字符串字面量语法，称为 **原始字符串字面量（Raw String Literal）**。它的作用是允许字符串中包	含换行符、引号、反斜杠等特殊字符，而不会被解释为转义字符
