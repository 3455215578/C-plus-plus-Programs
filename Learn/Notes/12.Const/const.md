#                                             const

const表明你声明的是一个不会被改变的常量，而不是一个变量。

指针可以进行两种操作：

1.改变指针指向的内存内容

2.改变指针指向的内存地址



对于引用：

##### 	引用就是内容。



### 一.const修饰变量

#### 1.指针常量

​	1.定义：**const 数据类型* 变量名 / 数据类型 const* 变量名**（这里**const修饰的是指针指向的内容(数据类型)**，因此指针指向的内容											                         不可被修改，而指针指向的内存地址可以被改变）。



#### 2.常量指针

​	1.定义：**数据类型* const 变量名**（这里const修饰的是指针变量本身，因此指针指向的内存地址不可被修改，而指针指向的内容可以 								    被修改。                                                                                                                                                                                         				                                                                

#### 3.拓展

​	1.定义：**const 数据类型* const 变量名**（既不能修改指针指向的内容，也不能修改指针指向的内存地址）



### 二.const修饰函数返回值

​	函数返回值用const修饰，说明函数返回的是一个不可被修改的常量。



### 三.const修饰类和方法

​	在类的方法的参数列表后面用const修饰，意味着这个方法不会修改类的成员变量。



​	在函数中，如果类作为函数参数并且被const修饰，那它就只能调用它的 **常量成员函数**（即那些声明为 `const` 的成员函数）



#### 	1.mutable(可变的)

​		对于被mutable修饰的变量，可以在const方法中被修改。
