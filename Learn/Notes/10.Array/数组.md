#                                                                                          数组



##### 数组就是指针。



### 一.在栈上创建数组

​	格式：**数据类型 数组名[ ]**



### 二.在堆上创建数组

​	使用new关键字动态分配：**数据类型 数组名 = new 数据类型[数组大小]**



### 三.在堆和栈上创建的区别

​	**二者最大的区别是生存期。**

​	在栈上创建的数组离开作用域后就会被销毁，而new分配的内存会一直存在到你手动释放。



​	如果有个函数，在函数内部创建了新数组并需要返回该数组，则必须用new来动态分配内存，否则该数组在离开函数后就被释放了。



​	对于在栈上创建的数组，可以用sizeof间接获取数组大小，但对堆分配的数组不适用，因为指针的内存空间固定为4或8个字节。
